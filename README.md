## 🎵 背景音乐

- 网页自带一段舒缓的环境音乐，右上角有 **「音乐」按钮** 可以随时开/关。
- 你选择过打开音乐后，下次打开网页会自动播放（在进入页面的第一次点击后响起）。
- 想换成自己的音乐？把音乐文件命名为 **`music.mp3`** 并上传到仓库根目录（和 `index.html` 同一层），网页就会自动优先播放你的音乐。若没有 `music.mp3`，则播放内置音乐。

## 📝 如何修改网页内容（重要）

网页的文字全部在 **`content.md`** 这个文件里，**不用动 `index.html`**。

### 修改步骤（在 GitHub 网页上操作，无需安装任何软件）

1. 打开仓库：https://github.com/ElaineCai216/AI-Handbook
2. 点击 `content.md` 文件
3. 点击右上角 ✏️ **铅笔图标**（Edit this file）
4. 直接修改文字（格式说明见下方）
5. 点右上角绿色 **Commit changes** 按钮 → 再点一次确认
6. 等 1-2 分钟，刷新你的网页链接即可看到更新：
   https://elainecai216.github.io/AI-Handbook/

> 提示：编辑页上方有 **Preview** 标签，可以先预览效果再保存。

### content.md 格式速查

| 你想做的 | 写法 |
| --- | --- |
| 新站点 | `# 01 我的身份定位`（井号 + 编号 + 标题） |
| 站点副标题 | `> 这一部分用于明确我的身份定位。` |
| 小节标题 | `## 1 · 我是谁？` |
| 普通段落 | 直接写文字 |
| 高亮文字 | `**重要的话**`（两个星号包起来） |
| 强调句/引用 | `> 这句话会显示成强调框` |
| 卡片表格 | `\| 名称 \| 说明 \|` 每行一张卡片 |
| 封面姓名 | 文件最上面的 `<!-- cover_name: ... -->` |
| 封面副标题 | 文件最上面的 `<!-- cover_meta: ... -->` |
